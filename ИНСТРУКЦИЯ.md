# Книги на планшеты — инструкция

Программа загружает книги (PDF, EPUB, FB2, DJVU, MOBI и другие) сразу на все подключённые планшеты. Подключили планшеты к компьютеру, перетащили книги в окно, нажали одну кнопку, и книги копируются на все устройства одновременно.

Кратко, как это устроено:

- программа работает на компьютере с Linux и открывается в браузере;
- планшеты подключаются по USB-кабелям через USB-хабы;
- на планшеты **ничего устанавливать не нужно**, только один раз включить «Отладку по USB»;
- книги, которые уже есть на планшете, повторно не копируются.

## Что понадобится

- Компьютер с Linux (Arch/Manjaro, Ubuntu, Debian, Mint и т.п.).
- **USB-хабы с отдельным блоком питания** (от сети). Например, 2–3 хаба по 10–16 портов на 30+ планшетов. Хабы без питания не потянут много устройств: планшеты будут отключаться.
- USB-кабели **для передачи данных**. Некоторые дешёвые кабели умеют только заряжать, и через них планшет не появится в программе.

## Шаг 1. Установка на компьютер (один раз) {#install}

1. Откройте терминал и установите программу `adb`. Через неё компьютер общается с планшетами.
  На Arch / Manjaro:

```
sudo pacman -S android-tools android-udev
sudo usermod -aG adbusers $USER
```

  На Ubuntu / Debian / Mint:

```
sudo apt install adb python3
sudo usermod -aG plugdev $USER
```

2. **Выйдите из системы и войдите снова** (или перезагрузите компьютер). Без этого Linux не даст программе доступ к планшетам по USB.
3. Положите папку `book-loader` в любое удобное место (например, оставьте в «Загрузках»).
4. Чтобы появился значок в меню приложений и на рабочем столе, один раз выполните в терминале:

```
~/Downloads/book-loader/install-shortcut.sh
```

> Python 3 обычно уже установлен в Linux. Ничего больше ставить не нужно.

## Шаг 2. Настройка каждого планшета (один раз) {#tablet}

Это нужно сделать с каждым планшетом **один раз**. На один планшет уходит 2–3 минуты.

### 2.1. Включить режим разработчика

1. Откройте **Настройки**.
2. Найдите раздел **«О планшете»**. На разных моделях он называется по-разному:
  - Samsung: «Сведения о планшете» → «Сведения о ПО»;
  - Lenovo, большинство остальных: «О планшете»;
  - Huawei / Honor: «О планшете»;
  - Xiaomi: «О планшете» (там нажимать на «Версия MIUI» или «Версия ОС»).
3. Найдите строку **«Номер сборки»** и **нажмите на неё 7 раз подряд**.
4. Если попросит, введите PIN-код планшета.
5. Появится надпись **«Вы стали разработчиком!»**.

### 2.2. Включить отладку по USB

1. Вернитесь в Настройки. Появился новый пункт **«Для разработчиков»** (иногда он лежит внутри «Система» или «Дополнительно»).
2. Откройте его и включите переключатель **«Отладка по USB»**. Подтвердите: «ОК».

### 2.3. Разрешить этот компьютер

1. Запустите программу на компьютере (см. шаг 3).
2. Подключите планшет кабелем к компьютеру (через хаб).
3. На экране планшета появится окно **«Разрешить отладку по USB?»**.
4. Поставьте галочку **«Всегда разрешать с этого компьютера»** и нажмите **«ОК»** (или «Разрешить»).
5. В программе карточка планшета станет зелёной: **«Готов»**.

Готово. Больше этот планшет ничего спрашивать не будет: вставили кабель, и программа его видит.

### Советы при настройке большого количества планшетов

- Настраивайте сразу пачкой. Подключите 10–15 штук к хабу, на каждом сделайте шаги 2.1–2.2, затем нажмите «Разрешить» на каждом по очереди.
- Программа автоматически называет планшеты «Планшет 1», «Планшет 2»… **Наклейте на планшеты номера**, совпадающие с названиями в программе. Если нужно найти, какой планшет в программе какой на столе, нажмите **«Найти»** на карточке: у этого планшета загорится экран. Переименовать карточку можно кнопкой **«Имя»**.
- Если на планшете нет пункта «Номер сборки» или «Для разработчиков», скорее всего, планшет заблокирован администратором (системой управления устройствами). Обратитесь к тому, кто выдал планшеты.

### Когда настройку придётся повторить

- После **сброса планшета к заводским настройкам**: шаги 2.1–2.3 заново.
- При работе **с другого компьютера**: только шаг 2.3.
- Иногда отладка выключается после **обновления Android**: снова включите шаг 2.2.

## Шаг 3. Работа с программой {#usage}

### Запуск

Нажмите на значок **«Книги на планшеты»** в меню приложений или на рабочем столе. Можно и через терминал: `~/Downloads/book-loader/run.sh`.

Откроется окно терминала (**не закрывайте его**, в нём работает программа) и страница в браузере. Если страница не открылась сама, откройте в браузере адрес **http://127.0.0.1:8765**.

Чтобы выключить программу, закройте окно терминала.

### 1. Добавить книги

- **Перетащите** файлы книг в рамку «Перетащите книги или папки сюда» (или нажмите на неё и выберите файлы).
- Можно перетащить **целую папку**: её внутренние папки сохранятся и на планшетах. Например, папка `5 класс` с книгами окажется на планшете как `Books/5 класс/...`.
- В поле **«В папку»** можно заранее написать, в какую папку положить новые книги, например `6 класс/История`.
- Добавленные книги **сохраняются в программе**. Их не нужно добавлять заново каждый раз: они хранятся в папке `book-loader/library`.
- Файлы других типов (не книги) программа пропустит.

### 2. Выбрать книги и планшеты

- Слева отметьте галочками нужные книги. Можно отметить всю папку галочкой рядом с её названием или «Выбрать все». Только что добавленные книги отмечаются автоматически.
- Справа нажмите **«Выбрать все готовые»** или отметьте нужные планшеты по одному (щелчок по названию).

### 3. Загрузить

Нажмите внизу **«Загрузить … на … планшетов»**. На каждой карточке будет виден прогресс. Можно не стоять у компьютера.

Когда всё закончится, внизу появится итог: сколько планшетов прошло успешно, а сколько с ошибкой.

- Книга, которая **уже есть** на планшете, повторно не копируется. На карточке будет написано «уже были: N». Поэтому смело загружайте весь набор на все планшеты: докопируется только недостающее.
- Если на каком-то планшете ошибка (например, отошёл кабель), поправьте причину и нажмите **«Повторить для ошибок»**. Загрузка повторится только на проблемных планшетах.
- Кнопка **«Остановить»** прерывает операцию. Уже скопированные книги останутся.

### Что значат цвета и надписи на карточках

- **Зелёная точка, «Готов»**: можно загружать.
- **Жёлтая, «Нажмите „Разрешить“ на экране планшета»**: см. шаг 2.3.
- **Красная, «Нет прав на USB»**: компьютер не настроен, см. «Частые проблемы».
- **Серая, «Не подключён»**: планшет был раньше, но сейчас не подключён. Так сразу видно, каких планшетов не хватает. Убрать его из списка навсегда можно кнопкой «Забыть».
- **«Заряд» и «Свободно»**: заряд батареи и свободное место. Если места мало, надпись станет красной.

### Другие возможности

- **Удалить книги с планшетов**: отметьте книги и планшеты и нажмите **«Удалить с планшетов»**. Книги сотрутся с планшетов, но останутся в списке программы.
- **Удалить книгу из программы**: отметьте её и нажмите «Удалить выбранные из списка». С планшетов она при этом **не** удаляется.
- **«Книги на нём»** на карточке: показывает, какие книги лежат на этом планшете и каких из списка программы на нём не хватает.
- **«Журнал»** вверху: история загрузок и удалений, когда и что было и на какие планшеты.
- **«Настройки»** (внизу правой части):
  - **папка для книг на планшете**: по умолчанию `/sdcard/Books`. Большинство читалок (ReadEra, Moon+ Reader, FBReader, Google Play Книги, PocketBook и др.) находят книги там сами;
  - **сколько планшетов загружать одновременно**: по умолчанию 10. Если планшеты часто отваливаются с ошибкой, уменьшите до 5. Если всё стабильно, можно увеличить;
  - **«Перезапустить ADB»**: помогает, если планшеты подключены, но программа их перестала видеть.

### Где книги на планшете

Книги лежат в папке **Books** во внутренней памяти планшета. В читалке:

- обычно книги появляются сами, иногда нужно нажать «Обновить» или «Сканировать» в библиотеке читалки;
- если читалка их не видит, в её настройках добавьте папку `Books` в список папок для поиска книг.

## Подключение по Wi-Fi (по желанию) {#wifi}

Основной и самый надёжный способ — USB. Wi-Fi можно использовать, если подключать кабель неудобно. Ограничения:

- компьютер и планшет должны быть **в одной сети Wi-Fi**;
- по Wi-Fi копирование заметно **медленнее**, особенно на много планшетов сразу;
- после **перезагрузки планшета** подключение по Wi-Fi пропадает, и его нужно включать заново.

Как включить:

1. Подключите планшет по USB (он должен быть «Готов»).
2. Нажмите **«Wi-Fi»** на его карточке. Появится вторая карточка с пометкой «(Wi-Fi)».
3. Теперь кабель можно отключить. Программа запомнит адрес и при следующем запуске попробует подключиться сама.

Если вы знаете IP-адрес планшета и на нём включена отладка по Wi-Fi, можно ввести адрес в поле «IP по Wi-Fi» и нажать «Подключить».

## Частые проблемы {#problems}

**Планшет вообще не появляется в программе**

- Проверьте, что включена «Отладка по USB» (шаг 2.2).
- Попробуйте другой кабель: возможно, этот только для зарядки.
- Подключите планшет напрямую в компьютер, без хаба. Если так он появился, у хаба не хватает питания или он неисправен.
- Нажмите «Перезапустить ADB» в настройках.

**«Нажмите „Разрешить“ на экране планшета», а окна на планшете нет**

- Разблокируйте экран планшета: окно появляется только на разблокированном экране.
- Отключите и снова подключите кабель.
- В «Для разработчиков» нажмите «Отозвать авторизации отладки по USB», переподключите кабель и нажмите «Разрешить» заново.

**«Нет прав на USB» (no permissions)**

Компьютер не настроен. Выполните ещё раз шаг 1 (команды `usermod`), затем **выйдите из системы и войдите снова**. На Arch проверьте, что установлен пакет `android-udev`.

**«Не хватает места»**

На планшете кончилась память. Посмотрите «Книги на нём», удалите ненужное («Удалить с планшетов») или освободите место на самом планшете.

**«Планшет отключился» / «Планшет не отвечает»**

Отошёл кабель, планшет разрядился или хабу не хватает питания. Проверьте подключение и нажмите «Повторить для ошибок». Если такое бывает часто, уменьшите в настройках число одновременно загружаемых планшетов.

**Читалка не видит книги**

Откройте в читалке библиотеку и нажмите «Обновить» / «Сканировать», либо добавьте папку `Books` в настройках читалки. Проверить, что книги действительно на планшете, можно кнопкой «Книги на нём».

**Страница пишет «Программа на компьютере не отвечает»**

Вы закрыли окно терминала с программой. Запустите программу снова значком.

## Где хранятся данные

Всё лежит внутри папки `book-loader`:

- `library/`: добавленные книги;
- `config.json`: названия планшетов и настройки;
- `journal.log`: журнал операций.

Чтобы перенести программу на другой компьютер, скопируйте всю папку `book-loader` целиком (на новом компьютере выполните шаг 1, а на планшетах — шаг 2.3).
